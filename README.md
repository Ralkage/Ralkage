# Hi, I'm Christian Lopez 👋

I'm a QA Automation Engineer and forum software developer who enjoys building practical tools for online communities, automation workflows, and developer-friendly extensions.

Most of my public work focuses on **Flarum extensions**, **PHP**, **JavaScript**, and tools that make community management easier.

## What I build

- 🧩 Flarum extensions for moderation, account management, ads, captchas, and user controls
- 🤖 AI-powered community tools using OpenAI, Claude, and OpenRouter
- 🧪 QA automation with Playwright, Cypress, Jenkins, and CI/CD pipelines
- 🛠️ Forum software add-ons and experiments for XenForo, Flarum, and custom apps
- ⚙️ Backend tools using PHP, JavaScript, TypeScript, Go, and Rust

## Featured projects

### 🔐 Account Lockout
Lock user accounts after too many failed login attempts.

[flarum-ext-account-lockout](https://github.com/Ralkage/flarum-ext-account-lockout)

### 📢 Ad Management
A full ad management system for Flarum with zones, analytics, approval workflows, and user self-service.

[flarum-ext-ad-management](https://github.com/Ralkage/flarum-ext-ad-management)

### 🛡️ Cap CAPTCHA
Self-hosted CAPTCHA extension for Flarum using proof-of-work.

[flarum-ext-cap-captcha](https://github.com/Ralkage/flarum-ext-cap-captcha)

### 🤖 Civility Filter
AI-powered civility filtering for Flarum posts using Anthropic Claude, OpenAI GPT, or OpenRouter.

[flarum-ext-civility-filter](https://github.com/Ralkage/flarum-ext-civility-filter)

### 🔗 Linked Accounts
Allows users to link multiple accounts and switch between them in Flarum.

[flarum-ext-linked-accounts](https://github.com/Ralkage/flarum-ext-linked-accounts)

### 🧼 Word Censor
Configurable word censoring with per-user toggles and guest/user defaults.

[flarum-ext-word-censor](https://github.com/Ralkage/flarum-ext-word-censor)
